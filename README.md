# Gemini Jarvis — AI Terminal Bridge

**Gemini Jarvis** — автономный терминальный ИИ-ассистент в стиле J.A.R.V.I.S. для macOS и Linux, построенный на базе официального SDK Google GenAI. Инструмент связывает большие языковые модели Gemini с локальной оболочкой (zsh/bash), позволяя выполнять системную диагностику, сетевой аудит, анализ логов и автоматизацию рутинных задач с помощью команд на естественном языке.

---

## Как это работает (Архитектура проекта)

В основе **Gemini Jarvis** лежат три инженерных механизма, обеспечивающих автономность, отказоустойчивость и визуальную эргономику:

### 1. Терминальный мост на базе Function Calling
Вместо простой генерации текста агент использует механизм вызова инструментов (Tools). Когда пользователь ставит задачу на естественном языке, модель самостоятельно формирует нужную bash/zsh-команду и вызывает локальную функцию-исполнитель:
* Команда запускается через изолированный подпроцесс с таймаутом 180 секунд.
* Глобальный контроллер состояния отслеживает команды смены директории и сохраняет текущий рабочий путь между вызовами.
* Стандартные потоки вывода (stdout и stderr) перехватываются, очищаются, при необходимости усекаются до 15 000 символов (для защиты контекстного окна от переполнения огромными логами) и возвращаются модели для анализа и формирования итогового технического отчета.

### 2. Двухконтурное резервирование (Dual-Core Auto-Failover)
Для обхода жестких квот API и пиковых нагрузок на серверы Google в скрипт встроена система горячего резервирования:
* **Основной контур (Primary Core):** по умолчанию все запросы направляются в мощную модель **gemini-4-argon**.
* **Слепок контекста (History Snapshot):** перед каждой отправкой сообщения скрипт сохраняет полную историю текущей сессии в оперативной памяти.
* **Аварийное переключение (Failover):** если основной кластер возвращает ошибку перегрузки (503 Unavailable) или исчерпания дневного лимита (429 Resource Exhausted), агент автоматически перехватывает исключение, инициализирует резервное ядро **gemini-flash-lite-latest**, загружает в него сохраненный слепок истории и выполняет запрос без разрыва диалога и потери контекста.

### 3. Схема потока данных
```text
[Запрос пользователя] 
       │
       ▼
[Снимок истории сессии (History Snapshot)]
       │
       ├──► Попытка 1: Ядро Gemini 4 Argon
       │         │ (При ошибке 429 / 503)
       │         ▼
       └──► Попытка 2: Резервное ядро Gemini Flash-Lite
                 │
                 ▼
      [Генерация Function Call] ──► [Локальный Subprocess (zsh/bash)]
                 ▲                                 │
                 └────── [Перехват stdout/stderr] ◄┘
                 │
                 ▼
    [Технический отчет Джарвиса в консоль]
```

### 4. Голографический интерфейс (TrueColor 3D HUD)
При запуске агент очищает экранный буфер терминала, считывает текущие габариты окна (колонки и строки) и центрирует массивный 15-строчный 3D-логотип в стиле ANSI Shadow. Посимвольный шейдер в реальном времени вычисляет 24-битный RGB-градиент, окрашивая лицевые грани букв плавным переходом от ледяного голубого к электрическому синему, а объемную тень — в глубокий сапфировый оттенок.

## Установка и быстрый старт

1. **Клонируйте репозиторий и создайте виртуальное окружение:**
```bash
git clone https://github.com/YOUR_USERNAME/Gemini-Jarvis.git
cd Gemini-Jarvis
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

2. **Экспортируйте ваш API-ключ из Google AI Studio:**
```bash
export GEMINI_API_KEY="ВАШ_API_КЛЮЧ"
```

3. **Запустите терминальный мост:**
```bash
python3 jarvis_shell.py
```

---

## Настройка глобального вызова (Alias)

Чтобы вызывать ассистента командой `jarvis` из любой папки вашей системы, добавьте ключ и алиас в конфигурационный файл вашей оболочки (**~/.zshrc** для macOS или **~/.bashrc** для Linux):

```bash
echo "export GEMINI_API_KEY=\"ВАШ_API_КЛЮЧ\"" >> ~/.zshrc
echo "alias jarvis=\"~/jarvis-cli/venv/bin/python3 ~/jarvis-cli/jarvis_shell.py\"" >> ~/.zshrc
source ~/.zshrc
```

## Управление в сессии

* Индикатор в строке ввода показывает активное ядро в текущий момент: `[ARGON]` или `[LITE]`.
* Для принудительного возврата на основное ядро введите: `/argon`
* Для штатного завершения сеанса введите: `exit`, `quit`, `выход` или нажмите `Ctrl+C`.
